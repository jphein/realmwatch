# App Split Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Split `src/app.js` (7,777 lines) into 12 focused modules to reduce AI agent context consumption, and add quick-win `.claudeignore`/CLAUDE.md navigation improvements.

**Architecture:** Extract cohesive sections from `src/app.js` into named module files. Each new module imports what it needs from `./config.js`, `./topology.js`, and sibling modules. `src/app.js` becomes a ~200-line init coordinator. No runtime behavior changes.

**Tech Stack:** Vanilla ES modules, esbuild bundle (`npm run build`). No tests (browser UI); verification is `npm run build` passing + manual smoke test.

**Spec:** `docs/superpowers/specs/2026-03-15-app-split-design.md`

---

**Common import header** — every new module starts with these (trim unused after extraction):
```js
'use strict';
import { WORLD_W, WORLD_H, WORLD_SCALE, _isMobile, _cpuCores, _perfTier, setPerfTier, _PERF, _mapTilt, setMapTilt, SSE_URL } from './config.js';

```

**Build command:** `npm run build`
**Section markers in app.js:** Use `grep -n "^// ──" src/app.js` to locate section boundaries.
**Discovery principle:** Before finalizing each module, run `grep -n "SYMBOL" src/app.js` for any private symbol you're not sure about, verify all call sites are in the right module.

## Key Implementation Notes

- `debug.js` ↔ `app.js` — debug reads `getSseConnected` from app.js; app.js imports from debug.js. Safe because `getSseConnected` is only read interactively.
- `spellbook.js` ↔ `layout.js` — spellbook calls `saveSettings` from layout.js; layout.js reads `getSpellPage`/`showSpellPage` from spellbook.js. Safe because all calls are triggered by user interaction, not at module init.
- `node-status.js` → `map-view.js` + `layout.js` — these stubs are created in Task 6 and replaced in Tasks 9/13.

- **Traffic-scale slider** (lines 905–916): stays in app.js, NOT in node-status.js. Only `let trafficScale = 1.0;` moves to traffic.js.
- **Census panel** (~line 5060): in panels.js by ownership, not adjacent to other panels.
- **`_bubbleFixedSize` + `_updateBubbleTotalScale`**: move from scale sliders (node-status territory) to map-view.js.
- **`liveOk` declaration** (~line 303): stays in app.js (SSE-only state).
- **`lastStatus` declaration** (~line 302): moves to node-status.js (owned by `updateUI`).
